API Reference

Complete reference for the public surface of file-json-db v1.5.0. Types are shown in TypeScript style for clarity.

JSONDB

new JSONDB(dbPath?: string) → JSONDB

Create or open a database at the given path (default ./database).

Methods

MethodReturnsDescription
collection(nameOrOptions)CollectionGet or create a collection
createCollection(nameOrOptions)CollectionAlias of collection
listCollections()string[]Names of collections found on disk
dropCollection(name)booleanDelete collection directory
unloadCollection(name)booleanRemove collection from memory
backup(backupRoot?, options?)string | nullSnapshot all collections
backupAsync(backupRoot?, options?)Promise<string | null>Async backup

CollectionOptions

interface CollectionOptions {
  name: string;
  autoId?: boolean;          // default false
  idField?: string;          // default '_id'
  idType?: 'auto' | 'uuid' | 'objectid';  // default 'auto'
  indexes?: string[];        // default []
  pretty?: boolean;          // default true
  maxPartSize?: number;      // default 256 * 1024
  maxRecords?: number | null;
  errorLevel?: 'debug' | 'ignore';  // default 'debug'
  keepIdIndex?: boolean;     // default false – compact ranges for auto IDs
}

Search (new in 1.5.0)

search(options: SearchOptions) → QueryBuilder
searchAsync(options: SearchOptions) → Promise<QueryBuilder>
interface SearchOptions {
  keyword: string;                 // required
  fields?: string[] | null;        // null = all fields
  exclude?: string[];              // fields to skip
  caseInsensitive?: boolean;       // default true
}

Simple keyword (contains) search. Returns a QueryBuilder so you can still chain .limit(), .sort(), .project(), .toArray(), etc. See the Search API page for full details and examples.

QueryBuilder

limit(n: number) → this
skip(n: number) → this
sort(spec: object) → this
project(spec: object) → this

Supports inclusion ({name:1}), exclusion ({password:0}), mixed (exclusion wins), and _id is kept by default (use _id:0 to hide). Improved in 1.5.0.

toArray() → object[]
first() → object | null
count() → number

Transaction

Same mutation methods as Collection (insert, updateOne, deleteMany, … plus their Async variants), plus:

commit() → Promise<boolean>
rollback() → Promise<boolean>
